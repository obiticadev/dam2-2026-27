# Adjuntos originales: archivo de conservación

Las copias extraídas del ZIP docente se conservan **sin corregir ni ejecutar**. No constituyen una solución funcional: `Main.java` contiene errores y falta la entidad `Usuario`.

La lectura, las ocho transcripciones y sus versiones revisadas están integradas en [4B — Configuración del aula](../contenidos/4B-proyecto-hibernate-oracle-maven.md#configuracion-del-aula). Los tres ZIP anidados conservan su contenido y huellas. No necesitan un apunte individual por archivo.

Estos archivos no se incorporarán como programas ejecutables a los apuntes. Para estudiar o para una incorporación posterior a Obsidian utilizar los Markdown de `contenidos/`, manteniendo la procedencia y las advertencias.
