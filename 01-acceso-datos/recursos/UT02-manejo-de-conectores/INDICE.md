<a id="descripcion"></a>
## Descripción

![Ilustración del material docente (contenido)](img/c65cfc450516a021.png) **Descripción**:

En esta unidad la persistencia de los datos se implementa con bases de datos relacionales. Por ello, aprenderemos a acceder a distintas bases de datos utilizando el lenguaje de programación Java utilizando conectores ó Drivers

Nos centraremos Java Database Connectivity (JDBC) es una interfaz de acceso a bases de datos estándar SQL que proporciona un acceso uniforme a una gran variedad de bases de datos relacionales.
