<Quiz id="py2-s1-01" title="Contar resultados booleanos">
¿Qué imprime?

```python
def mayor(edad):
    return edad >= 18
r = mayor(18) + mayor(12) + mayor(20)
print(r, type(r).__name__)
```

- [x] `2 int`
  > True aporta 1 y False aporta 0; la suma aritmética produce el entero 2, no un bool.
- [ ] `True bool`
  > Eso confunde la suma aritmética con una operación lógica: aquí se suman tres valores.
- [ ] `2 bool`
  > El valor es 2, pero su tipo es int; bool solo tiene los valores True y False.
- [ ] No imprime nada: `TypeError`.
  > Los booleanos sí admiten suma numérica en Python.

Repasar: F, ejercicio 3; precisión añadida: aritmética de booleanos.

<Quiz id="py2-s1-04" title="Mostrar no es devolver">

<Quiz id="py2-s1-19" title="La vuelta de la recursión">
¿Qué imprime?

```python
def traza(n):
    if n == 0:
        return
    print(n)
    traza(n - 1)
    print(n)
traza(2)
```

- [x] `2 / 1 / 1 / 2`
  > Primero imprimen las llamadas al bajar; al retornar se reanudan las pendientes en orden inverso.
- [ ] `2 / 1 / 0 / 1 / 2`
  > El caso con 0 retorna antes de ejecutar los print.
- [ ] `2 / 2 / 1 / 1`
  > El segundo print de la llamada con 2 espera a que termine la llamada con 1.
- [ ] `2 / 1 / None`
  > El retorno None no se imprime por sí mismo: no hay un print exterior envolviendo la llamada.

Repasar: T c (pila de llamadas); traza añadida.
</Quiz>
