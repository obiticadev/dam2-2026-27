<Quiz id="py2-s2-01" title="Una sangría extra">
¿Qué ocurre al ejecutar este archivo completo? No hay tabuladores.

```python
print("inicio")
def f():
    x = 1
        return x
print(f())
```

- [ ] Imprime `inicio` y falla con `IndentationError`.
  > En un archivo completo el error de compilación se detecta antes de ejecutar el primer print.
- [x] No imprime nada: `IndentationError`.
  > return tiene un nivel extra de sangría sin un bloque que lo permita; no se ejecuta ninguna línea.
- [ ] Imprime `inicio / 1`.
  > No toda sangría adicional es válida: aquí no hay if, for ni otra cabecera que abra ese nivel.
- [ ] No imprime nada: `TypeError`.
  > El fallo es de estructura del código, no de tipos durante una llamada.

Repasar: T a (cuerpo indentado); precisión añadida: compilación del archivo.
</Quiz>

<Quiz id="py2-s2-02" title="Dos espacios también pueden ser válidos">
¿Qué imprime? El cuerpo usa exactamente dos espacios por nivel.

```python
def f(n):
  if n > 0:
    return n + 1
  return 0
print(f(1))
```

- [ ] No imprime nada: `IndentationError`.
  > Cuatro espacios es la convención recomendada, no el único tamaño válido para la sangría.
- [ ] `0`
  > El return 0 se omite porque la rama positiva ya ha retornado.
- [x] `2`
  > Los niveles son coherentes; el if se cumple y devuelve 1 + 1.
- [ ] `None`
  > La ruta ejecutada sí tiene return explícito.

Repasar: T a; precisión añadida: sangría coherente frente a convención de estilo.
</Quiz>

<Quiz id="py2-s2-03" title="Return fuera de la función">
¿Qué ocurre al ejecutar el archivo completo?

```python
def f():
    x = 2
return x
print(f())
```

- [x] No imprime nada: `SyntaxError`.
  > return está en el nivel del módulo y solo puede usarse dentro de una función.
- [ ] No imprime nada: `NameError`.
  > No se llega a evaluar x: antes se rechaza return fuera de función.
- [ ] `2`
  > La desindentación deja return fuera del cuerpo, por lo que no devuelve la x local.
- [ ] `None`
  > No se puede ejecutar la función porque el archivo no compila.

Repasar: T a (cuerpo y sentencia return).
</Quiz>

<Quiz id="py2-s2-06" title="El mismo parámetro recibe dos valores">

- [ ] `dentro / 4`

<Quiz id="py2-s2-08" title="Lectura de una local antes de asignarla">
¿Qué ocurre?

```python
contador = 8
def aumentar():
    contador += 1
    return contador
print(aumentar())
```

- [ ] `9`
  > La asignación dentro de la función hace local el nombre; no se modifica implícitamente la global.
- [ ] `8`
  > La llamada falla antes de poder devolver un resultado.
- [ ] No imprime nada: `TypeError`.
  > Sumar enteros sería válido; el problema es que la local aún no tiene valor.
- [x] No imprime nada: `UnboundLocalError`.
  > += necesita leer la local contador antes de que se le haya asignado un valor; se pide la clase específica.

Repasar: F, ejercicios 4 y 10; precisión añadida: resolución de variables locales.
</Quiz>

<Quiz id="py2-s2-18" title="La división ocurre antes de la siguiente llamada">

- [ ] `1.0`
  > Ese retorno solo se aplica si n vale exactamente 1.

<Quiz id="py2-s2-20" title="Una local no aparece fuera">

- [ ] `4`

- [ ] `None`
  > El print no recibe None: la evaluación de resultado falla antes de llamarlo.
- [ ] No imprime nada: `UnboundLocalError`.
  > Aquí el nombre se busca en el módulo y no existe; no es una local de función leída antes de asignarla.

Repasar: T a; F, ejercicio 10.
