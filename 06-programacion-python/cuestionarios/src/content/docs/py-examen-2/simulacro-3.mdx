<Quiz id="py2-s3-01" title="El cortocircuito evita una división">
¿Qué imprime?

```python
def comprobar(x):
    return x != 0 and 8 / x > 1
print(comprobar(0), comprobar(4))
```

- [ ] No imprime nada: `ZeroDivisionError`.
  > Con x igual a cero, el primer operando es False y and no evalúa la división.
- [ ] `True True`
  > Cero incumple la primera condición de la función.
- [x] `False True`
  > La primera llamada se corta en False; en la segunda, 8 / 4 es 2 y supera 1.
- [ ] `False False`
  > Con 4 se cumplen las dos condiciones.

Repasar: F, ejercicio 14 (and); precisión añadida: evaluación en cortocircuito.
</Quiz>

<Quiz id="py2-s3-02" title="Or no devuelve siempre un bool">
¿Qué imprime?

```python
def elegir(x):
    return x or 5
print(elegir(0), elegir(2))
```

- [x] `5 2`
  > or devuelve un operando: 0 es falso y da paso a 5; 2 es verdadero y se devuelve directamente.
- [ ] `True True`
  > or no convierte automáticamente los operandos en valores bool.
- [ ] `0 2`
  > Con el cero se evalúa y devuelve el segundo operando.
- [ ] `5 5`
  > El segundo operando no sustituye a un primer operando que ya sea verdadero.

Repasar: T a; precisión añadida: valor de retorno de operadores lógicos.
</Quiz>

<Quiz id="py2-s3-03" title="Argumentos evaluados de izquierda a derecha">
¿Qué imprime?

```python
def marca(n):
    print(n)
    return n
print(marca(1) + marca(2))
```

- [ ] `3 / 1 / 2`
  > El print exterior espera a evaluar la suma de sus argumentos.
- [ ] `1 / 3 / 2`
  > La suma no puede completarse sin obtener primero el retorno de marca(2).
- [ ] `2 / 1 / 3`
  > Se evalúa primero el operando de la izquierda, marca(1).
- [x] `1 / 2 / 3`
  > Cada llamada imprime su número durante la evaluación; después el print exterior muestra 1 + 2.

Repasar: T a; precisión añadida: orden de evaluación de expresiones y llamadas.
</Quiz>

<Quiz id="py2-s3-04" title="Cambiar el orden por nombre">

```python
def resta(a, b=2):

print(resta(b=5, a=3), resta(3))
```

  > Los argumentos con nombre no se asocian por el orden en que aparecen escritos.

- [ ] `-2 -2`

  > Ambas operaciones son válidas: concatenación de cadenas y suma de bool con int.
- [x] `23 3`

Repasar: F, ejercicio 12; precisión añadida: operadores según el tipo recibido.

<Quiz id="py2-s3-12" title="Límite impar en una suma de pares">

def pares(n):

        return 0
    if n % 2 != 0:
        return pares(n - 1)
    return n + pares(n - 2)
print(pares(5))

- [ ] `15`
  > Eso sumaría todos los naturales; los impares no se acumulan en esta función.
- [x] `6`

- [ ] `9`
  > Eso sumaría 5 + 3 + 1, justamente los impares que se descartan.
- [ ] `4`
  > Tras sumar 4 todavía se procesa el 2 antes del caso base.

Repasar: R, ejercicio 26.

<Quiz id="py2-s3-14" title="El cero como fin del recorrido de dígitos">
¿Qué imprime esta función concreta? Se prueba también fuera del dominio positivo del enunciado.

```python
def contar(n, d):
    if n == 0:
        return 0
    return (n % 10 == d) + contar(n // 10, d)
print(contar(10, 0), contar(0, 0))
```

- [x] `1 0`
  > El cero de 10 sí se inspecciona; n igual a 0 entra directamente en el caso base y no se inspecciona.
- [ ] `1 1`

- [ ] `0 0`
  > En la primera llamada, 10 % 10 sí vale 0 y aporta True, equivalente a 1 en la suma.
- [ ] `True False`
  > Las sumas recursivas producen enteros y el caso base devuelve el entero 0.

Repasar: R, ejercicio 30; precisión añadida: suma de booleanos y entrada cero.
</Quiz>

<Quiz id="py2-s3-16" title="El umbral de 1024 bytes">
¿Qué imprime esta versión reducida a bytes y KB?

```python
def tamano(n):
    if n >= 1024:
        return f"{n / 1024:.2f} KB"
    return f"{n} bytes"
print(tamano(1024))
```

- [ ] `1024 bytes`
  > El operador mayor o igual incluye exactamente el umbral 1024.
- [x] `1.00 KB`
  > 1024 dividido entre 1024 da 1; el formato .2f muestra dos decimales.
- [ ] `1 KB`
  > La conversión numérica es correcta, pero el formato solicita dos cifras decimales.
- [ ] `1.00 MB`
  > Este fragmento solo convierte una vez de bytes a KB, no a MB.

Repasar: RA3, requisito 4 (variante reducida para cálculo mental).

<Quiz id="py2-s3-19" title="Olvidar acumular el retorno de una subcarpeta">
¿Qué imprime esta simplificación de dos niveles, sin acceso al disco?

```python
def recorrer(nivel, h):
    if nivel == 0:
        h.append("fichero")
        return 4
    total = 0
    recorrer(nivel - 1, h)
    return total
h = []
print(recorrer(1, h), h)
```

- [ ] `4 ['fichero']`
  > El retorno 4 de la llamada interna se ignora: no se suma a total.
- [ ] `0 []`
  > Aunque se pierdan los bytes devueltos, la mutación de la lista compartida sí permanece.
- [ ] `None ['fichero']`
  > La llamada exterior sí tiene return: devuelve su total local, que vale 0.
- [x] `0 ['fichero']`
  > El historial registra el archivo, pero faltaría acumular el retorno de la subllamada para sumar sus bytes.

Repasar: RA3, requisitos 7 y 8.
</Quiz>
