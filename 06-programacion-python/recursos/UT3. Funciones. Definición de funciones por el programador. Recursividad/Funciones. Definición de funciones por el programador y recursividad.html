UT3. Funciones. Definición de funciones por el programador y recursividad

Introducción

En las unidades anteriores se ha trabajado con programas escritos como una única secuencia de instrucciones (con sus estructuras de selección, repetición, salto y control de excepciones). A medida que un programa crece, escribirlo todo "de un tirón" se vuelve difícil de leer, de probar y de reutilizar.

La programación modular resuelve este problema dividiendo el programa en piezas más pequeñas e independientes —los módulos— siendo la función la unidad básica de modularización dentro de un mismo archivo o módulo Python.

Esta unidad de trabajo presenta cómo definir funciones propias en Python, cómo se les pasan los datos con los que trabajan (y la diferencia clave entre el paso de parámetros por valor y por referencia), y una técnica muy ligada al uso de funciones: la recursividad, es decir, la capacidad de una función para llamarse a sí misma.

a) Programación modular y definición de funciones

La programación modular consiste en dividir un programa en partes más pequeñas, independientes y con una responsabilidad concreta, denominadas módulos, que después se combinan para formar el programa completo. Sus principales ventajas son:

  • Reutilización: una misma función puede invocarse tantas veces como se necesite, desde distintos puntos del programa, sin reescribir el código.
  • Legibilidad: un programa dividido en funciones con nombres descriptivos es más fácil de leer y de entender.
  • Mantenimiento: si hay que corregir o mejorar una funcionalidad, basta con modificar la función correspondiente, sin tocar el resto del programa.
  • División del trabajo: distintas personas de un equipo pueden encargarse de programar funciones diferentes de un mismo proyecto.
  • Prueba y depuración: cada función puede probarse de forma aislada, lo que facilita localizar errores.

Una función es un bloque de código con nombre propio que realiza una tarea concreta, que puede recibir datos de entrada (parámetros) y que puede devolver un resultado (valor de retorno). En Python, una función se define con la palabra reservada def:

def nombre_funcion(parametro1, parametro2):
    """Docstring: qué hace la función, sus parámetros y qué devuelve."""
    # cuerpo de la función
    resultado = parametro1 + parametro2
    return resultado           # sentencia de retorno (opcional)

Elementos de una función:

  • Cabecera: def + nombre de la función + lista de parámetros entre paréntesis + dos puntos. Los parámetros son las variables que recibe la función; los argumentos son los valores concretos con los que se la invoca en cada llamada.
  • Cuerpo: el bloque de instrucciones indentado que se ejecuta cada vez que se llama a la función.
  • return (opcional): finaliza la función y devuelve un valor al punto donde se la invocó (ya visto en la unidad anterior, apartado de estructuras de salto). Si una función no tiene return, devuelve implícitamente None.
  • Llamada o invocación: la instrucción nombre_funcion(argumento1, argumento2) que ejecuta el código de la función con esos valores concretos.

Parámetros con valor por defecto: permiten que un argumento sea opcional en la llamada, tomando un valor predeterminado si no se indica:

def saludar(nombre, saludo="Hola"):
    return saludo + ", " + nombre

print(saludar("Ana"))            # Hola, Ana
print(saludar("Luis", "Buenas")) # Buenas, Luis

Ámbito de las variables: las variables definidas dentro de una función son locales (solo existen mientras se ejecuta la función), mientras que las definidas fuera son globales.

Python es especialmente adecuado para resolver problemas de matemática elemental mediante funciones, ya que dispone del módulo math y permite encapsular fácilmente fórmulas (áreas, ecuaciones, series, comprobación de primos, máximo común divisor...) como funciones reutilizables.

Ejemplo en Python

import math

def es_primo(n):
    """Determina si un número entero n es primo."""
    if n < 2:
        return False
    for divisor in range(2, int(math.sqrt(n)) + 1):
        if n % divisor == 0:
            return False
    return True

def area_triangulo(base, altura):
    """Calcula el área de un triángulo a partir de su base y altura."""
    return (base * altura) / 2

def maximo_comun_divisor(a, b):
    """Calcula el m.c.d. de dos números mediante el algoritmo de Euclides."""
    while b != 0:
        a, b = b, a % b
    return a

print(es_primo(17))                 # True
print(area_triangulo(6, 4))         # 12.0
print(maximo_comun_divisor(48, 18)) # 6

b) Paso de parámetros: por valor y por referencia

Cuando se invoca una función con argumentos, es fundamental entender qué le llega realmente a la función: una copia del valor, o una referencia al mismo objeto en memoria que la variable original. De ello depende si los cambios que la función hace sobre el parámetro afectan o no a la variable que se pasó desde fuera.

  • Paso por valor: la función recibe una copia independiente del valor. Cualquier modificación que la función haga sobre el parámetro no afecta a la variable original, porque son dos espacios de memoria distintos.
  • Paso por referencia: la función recibe una referencia (un "enlace") al mismo objeto que la variable original. Si la función modifica el contenido de ese objeto, el cambio sí es visible desde fuera de la función, porque no hay copia: ambas variables apuntan al mismo objeto en memoria.

¿Cómo funciona esto en Python? Python no distingue "por valor" y "por referencia" de forma explícita como otros lenguajes (por ejemplo, C++ con &); lo que ocurre depende de si el tipo de dato del argumento es mutable o inmutable:

  • Los tipos inmutables (int, float, bool, str, tuple) se comportan, en la práctica, como paso por valor: dentro de la función se puede reasignar el parámetro a un nuevo valor, pero eso no cambia el objeto original, solo hace que el nombre local apunte a otro objeto distinto.
  • Los tipos mutables (list, dict, set, y en general los objetos definidos por el programador) se comportan, en la práctica, como paso por referencia: si dentro de la función se modifica el contenido del objeto (por ejemplo, añadiendo un elemento a una lista, o asignando a una posición del objeto), ese cambio sí se observa fuera de la función, porque el parámetro y la variable original apuntan al mismo objeto en memoria. Los métodos y operaciones concretas de las listas (.append(), .pop(), indexación...) se estudiarán en detalle en la siguiente unidad; en el ejemplo siguiente se usa únicamente .append(), de forma anticipada, porque es imprescindible para poder ilustrar el paso por referencia.

Esta distinción, que suele llamarse "paso por asignación de objetos" (pass-by-object-reference), es una de las fuentes de errores más habituales en programadores que empiezan con Python, por lo que conviene practicarla con cuidado.

Ejemplo en Python

# --- Tipo inmutable: se comporta como paso por valor ---
def incrementar(numero):
    numero = numero + 1   # esto NO modifica la variable original: crea un valor local nuevo
    return numero

x = 5
resultado = incrementar(x)
print(x, resultado)   # 5 6  -> 'x' no ha cambiado

# --- Tipo mutable: se comporta como paso por referencia ---
def añadir_elemento(lista):
    lista.append(100)   # esto SÍ modifica el objeto original, porque es el mismo objeto en memoria

numeros = [1, 2, 3]
añadir_elemento(numeros)
print(numeros)   # [1, 2, 3, 100]  -> la lista original SÍ ha cambiado

# --- Cuidado: reasignar un parámetro mutable NO afecta al original ---
def sustituir_lista(lista):
    lista = [0, 0, 0]   # esto crea un objeto nuevo y local; NO afecta a la lista original

datos = [1, 2, 3]
sustituir_lista(datos)
print(datos)   # [1, 2, 3]  -> no ha cambiado, porque 'lista' pasó a apuntar a OTRO objeto

c) Recursividad

Una función es recursiva cuando, en su propio cuerpo, contiene una llamada a sí misma. La recursividad es una alternativa a la iteración (bucles for/while) para resolver problemas que pueden descomponerse en subproblemas más pequeños del mismo tipo que el problema original.

Toda función recursiva bien construida necesita dos elementos:

  1. Caso base: la condición en la que la función deja de llamarse a sí misma y devuelve un resultado directo. Es imprescindible: sin caso base, la función se llamaría a sí misma indefinidamente hasta agotar la memoria disponible (error RecursionError en Python).
  2. Caso recursivo: la llamada de la función a sí misma con un argumento "más cercano" al caso base (por ejemplo, un número más pequeño), de forma que la sucesión de llamadas converja finalmente hacia el caso base.

Relación entre iteración y recursividad: cualquier problema resoluble con recursividad puede resolverse también con iteración, y viceversa; la elección entre una y otra suele ser una cuestión de claridad del código (algunos problemas, como recorrer estructuras jerárquicas o dividir un problema en mitades, se expresan de forma mucho más natural con recursividad) y de eficiencia (una solución iterativa suele consumir menos memoria, ya que la recursividad utiliza la pila de llamadas —call stack— y cada llamada recursiva ocupa espacio en memoria hasta que se resuelve).

Iteración Recursividad
Mecanismo Bucle (for/while) que repite un bloque Función que se llama a sí misma
Control de la repetición Condición del bucle Caso base
Uso de memoria Generalmente constante Crece con cada llamada (pila de llamadas)
Legibilidad Más directa en problemas "planos" Más natural en problemas definidos de forma recursiva (factorial, Fibonacci, árboles...)

Ejemplo en Python

# Factorial: versión iterativa (ya vista en el apartado a) y versión recursiva
def factorial_iterativo(n):
    resultado = 1
    for i in range(2, n + 1):
        resultado *= i
    return resultado

def factorial_recursivo(n):
    if n in (0, 1):        # caso base
        return 1
    return n * factorial_recursivo(n - 1)   # caso recursivo

print(factorial_iterativo(5))   # 120
print(factorial_recursivo(5))   # 120

# Sucesión de Fibonacci de forma recursiva
def fibonacci(n):
    """Devuelve el n-ésimo término de la sucesión de Fibonacci (0, 1, 1, 2, 3, 5, 8...)."""
    if n <= 1:              # caso base
        return n
    return fibonacci(n - 1) + fibonacci(n - 2)   # caso recursivo (dos llamadas)

for i in range(8):
    print(fibonacci(i))   # 0, 1, 1, 2, 3, 5, 8, 13 (uno por línea)

# Suma de los dígitos de un número de forma recursiva
def suma_digitos(numero):
    """Suma los dígitos de un número entero positivo, de forma recursiva."""
    if numero < 10:                       # caso base: un solo dígito
        return numero
    return numero % 10 + suma_digitos(numero // 10)   # caso recursivo

print(suma_digitos(1234))   # 10  (1 + 2 + 3 + 4)

    def potencia(base, exponente):
    """Calcula 'base' elevado a 'exponente' de forma recursiva, sin usar **.
