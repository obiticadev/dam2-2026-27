UT3. Ejercicios adicionales

Introducción

Este documento recoge treinta ejercicios pensados para practicar los contenidos de la UT3, organizados en tres bloques: diez ejercicios de programación modular (definición de funciones, parámetros con valor por defecto, documentación con docstrings, y paso de parámetros por valor y por referencia), diez ejercicios de desarrollo de módulos Python (crear varias funciones en un archivo independiente e importarlas y utilizarlas desde un programa principal distinto, incluyendo en todos los casos un bloque de autoprueba protegido con if __name__ == "__main__":), y diez ejercicios más de programación recursiva (funciones que se llaman a sí mismas, identificando en cada caso el caso base y el caso recursivo).

Todos los ejercicios utilizan únicamente elementos ya trabajados hasta esta unidad (no se emplean listas, tuplas, sets ni diccionarios, salvo el uso puntual de .append() sobre una lista ya creada, necesario para practicar el paso de parámetros por referencia, y el uso de una tupla como valor de retorno, ya visto como tipo inmutable).

Ejercicio 1: Conversor de Celsius a Fahrenheit

Enunciado: Codifica una función celsius_a_fahrenheit(celsius) que convierta una temperatura de grados Celsius a grados Fahrenheit, aplicando la fórmula F = C · 9/5 + 32. 

"""
Conversor de grados Celsius a Fahrenheit.

Módulo con una función que convierte una temperatura de grados Celsius a
grados Fahrenheit, aplicando la fórmula F = C * 9/5 + 32.
"""

def celsius_a_fahrenheit(celsius):
    """Convierte una temperatura de grados Celsius a grados Fahrenheit.

    Parámetros:
        celsius (float): temperatura en grados Celsius.
    Devuelve:
        float: la temperatura equivalente en grados Fahrenheit.
    """
    fahrenheit = celsius * 9 / 5 + 32
    return fahrenheit


print(celsius_a_fahrenheit(0))     # 32.0
print(celsius_a_fahrenheit(100))   # 212.0
print(celsius_a_fahrenheit(37))    # 98.6

Salida

32.0
212.0
98.6

Ejercicio 2: Calculadora de precio con IVA

Enunciado: Codifica una función calcular_precio_con_iva(precio, iva=21), con un parámetro por defecto, que calcule el precio final de un producto aplicando el porcentaje de IVA indicado (21 % si no se especifica otro).

"""
Calculadora de precio con IVA.

Módulo con una función que calcula el precio final de un producto aplicando
un porcentaje de IVA, que por defecto es del 21 %.
"""

def calcular_precio_con_iva(precio, iva=21):
    """Calcula el precio final de un producto aplicando un porcentaje de IVA.

    Parámetros:
        precio (float): precio del producto sin IVA.
        iva (float): porcentaje de IVA a aplicar (por defecto, 21).
    Devuelve:
        float: el precio final, con el IVA ya incluido.
    """
    precio_final = precio + (precio * iva / 100)
    return precio_final


print(calcular_precio_con_iva(100))       # 121.0
print(calcular_precio_con_iva(100, 10))   # 110.0
print(calcular_precio_con_iva(50, 4))     # 52.0

Salida

121.0
110.0
52.0

Ejercicio 4: Contador de consonantes

Enunciado: Codifica una función contar_consonantes(palabra) que recorra una palabra letra a letra, con un bucle for, y devuelva cuántas consonantes contiene. 

"""
Contador de consonantes de una palabra.

Módulo con una función que cuenta cuántas consonantes contiene una palabra,
recorriéndola letra a letra con un bucle for.
"""

VOCALES = "aeiouAEIOUáéíóúÁÉÍÓÚ"

def contar_consonantes(palabra):
    """Cuenta cuántas consonantes contiene una palabra.

    Parámetros:
        palabra (str): la palabra o texto a analizar.
    Devuelve:
        int: el número de letras que no son vocales ni espacios.
    """
    contador = 0
    for letra in palabra:
        if letra.isalpha() and letra not in VOCALES:
            contador += 1
    return contador


print(contar_consonantes("ordenador"))       # 5
print(contar_consonantes("Python"))          # 5
print(contar_consonantes("aeiou"))           # 0

Salida

5
5
0

Ejercicio 5: Perímetro y área de un rectángulo

Enunciado: Codifica una función calcular_perimetro_area_rectangulo(base, altura) que calcule a la vez el perímetro y el área de un rectángulo, devolviendo ambos valores en una tupla.

"""
Perímetro y área de un rectángulo.

Módulo con una función que calcula, a la vez, el perímetro y el área de un
rectángulo, devolviendo ambos valores en una tupla.
"""

def calcular_perimetro_area_rectangulo(base, altura):
    """Calcula el perímetro y el área de un rectángulo.

    Parámetros:
        base (float): longitud de la base del rectángulo.
        altura (float): longitud de la altura del rectángulo.
    Devuelve:
        tuple: una tupla (perimetro, area) con los dos valores calculados.
    """
    perimetro = 2 * (base + altura)
    area = base * altura
    return (perimetro, area)


perimetro, area = calcular_perimetro_area_rectangulo(5, 3)
print(perimetro)   # 16
print(area)         # 15

print(calcular_perimetro_area_rectangulo(4, 4))   # (16, 16)

Salida

16
15

Enunciado: Codifica una función saludo_personalizado(nombre, idioma="es"), con un parámetro por defecto, que devuelva un saludo con el nombre recibido en español, inglés o francés según el código de idioma indicado.

"""
Saludo personalizado en varios idiomas.

Módulo con una función que devuelve un saludo personalizado con el nombre
recibido, en el idioma indicado (español por defecto).
"""

def saludo_personalizado(nombre, idioma="es"):
    """Devuelve un saludo personalizado en el idioma indicado.

    Parámetros:
        nombre (str): nombre de la persona a saludar.
        idioma (str): código del idioma del saludo ("es", "en" o "fr"),
            por defecto "es".
    Devuelve:
        str: el saludo completo en el idioma solicitado, o un mensaje de
        aviso si el idioma no está disponible.

    if idioma == "es":
        saludo = "Hola, " + nombre + "!"
    elif idioma == "en":
        saludo = "Hello, " + nombre + "!"
    elif idioma == "fr":
        saludo = "Bonjour, " + nombre + "!"
    else:
        saludo = "Idioma no disponible para " + nombre
    return saludo

print(saludo_personalizado("Karl", "de"))       # Idioma no disponible para Karl

Ejercicio 9: Comprobador de triángulo rectángulo

Enunciado: Codifica una función es_triangulo_rectangulo(a, b, c) que, a partir de las longitudes de los tres lados de un triángulo, determine si es rectángulo aplicando el teorema de Pitágoras (usa el módulo math).

"""
Comprobador de triángulo rectángulo.

Módulo con una función que determina si un triángulo, dados los tres lados,
es rectángulo, aplicando el teorema de Pitágoras.
"""

import math

def es_triangulo_rectangulo(a, b, c):
    """Determina si un triángulo de lados a, b y c es rectángulo.

    Aplica el teorema de Pitágoras: el cuadrado del lado mayor (hipotenusa)
    debe ser igual a la suma de los cuadrados de los otros dos lados
    (catetos).

    Parámetros:
        a, b, c (float): las longitudes de los tres lados del triángulo.
    Devuelve:
        bool: True si el triángulo es rectángulo, False en caso contrario.
    """
    hipotenusa = max(a, b, c)
    suma_cuadrados_catetos = a ** 2 + b ** 2 + c ** 2 - hipotenusa ** 2
    return math.isclose(hipotenusa ** 2, suma_cuadrados_catetos)


print(es_triangulo_rectangulo(3, 4, 5))    # True
print(es_triangulo_rectangulo(5, 6, 7))    # False
print(es_triangulo_rectangulo(6, 8, 10))   # True

Salida

True
False
True

Bloque 2: Desarrollo de módulos Python

En este bloque cada módulo define más de una función relacionada entre sí (en algunos casos, una función reutiliza internamente otra del mismo módulo) y se utiliza desde un programa principal que la importa, en lugar de definir las funciones en el mismo archivo donde se usan, tal y como se ha hecho en el bloque 1. Además, cada módulo incluye al final un bloque de código protegido con if __name__ == "__main__": que prueba sus propias funciones: ese bloque no se ejecuta cuando el módulo se importa desde principal.py, pero sí se ejecuta cuando el archivo del módulo se ejecuta directamente. Por eso, para cada ejercicio se muestran las dos salidas posibles. Ambos archivos deben guardarse en la misma carpeta del proyecto.

Ejercicio 11: Módulo ejecutable con bloque if __name__ == "__main__":

Enunciado: Crea un módulo modulo_saludo.py con dos funciones, saludar(nombre) y despedir(nombre), y, al final del archivo, un bloque de código de prueba protegido con if __name__ == "__main__": que pruebe ambas funciones y que solo debe ejecutarse cuando el archivo se ejecuta directamente. Crea un programa principal principal.py que importe las dos funciones y las use; comprueba también qué ocurre al ejecutar modulo_saludo.py directamente.

Módulo modulo_saludo.py:

"""
Módulo de saludo y despedida, con bloque de pruebas propio.

Contiene las funciones saludar(nombre) y despedir(nombre) y, al final, un
bloque de código de prueba que solo se ejecuta cuando este archivo se
ejecuta directamente, no cuando se importa desde otro programa.
"""

def saludar(nombre):
    """Devuelve un saludo personalizado con el nombre recibido."""
    return "¡Hola, " + nombre + "!"


def despedir(nombre):
    """Devuelve una despedida personalizada con el nombre recibido."""
    return "¡Hasta pronto, " + nombre + "!"


if __name__ == "__main__":
    print("Este mensaje SOLO aparece si se ejecuta este archivo directamente.")
    print(saludar("modo de prueba"))
    print(despedir("modo de prueba"))

Programa principal principal.py:

"""
Programa principal que usa el módulo 'modulo_saludo'.

Al importar el módulo, el bloque protegido por
'if __name__ == "__main__":' NO se ejecuta: solo se ejecuta el código de
nivel superior del módulo (las definiciones de las funciones) y, después,

Ejercicio 12: Módulo de operaciones aritméticas básicas

Enunciado: Crea un módulo operaciones.py con cuatro funciones: sumar(a, b), restar(a, b), multiplicar(a, b) y dividir(a, b) (esta última debe controlar con try/except la división entre cero, devolviendo None en ese caso). Módulo operaciones.py:

"""
Módulo de operaciones aritméticas básicas.

Contiene funciones para sumar, restar, multiplicar y dividir dos números,
pensadas para ser reutilizadas desde otros programas.
"""

def sumar(a, b):
    """Devuelve la suma de dos números."""
    return a + b


def restar(a, b):
    """Devuelve la resta de dos números (a - b)."""
    return a - b


def multiplicar(a, b):
    """Devuelve el producto de dos números."""
    return a * b


def dividir(a, b):
    """Devuelve la división de dos números (a / b).

    Controla con try/except el caso de que 'b' sea 0.

    Devuelve:
        float: el resultado de a / b, o None si b es 0.
    """
    try:
        return a / b
    except ZeroDivisionError:
        print("Error: no se puede dividir entre cero.")
        return None


if __name__ == "__main__":
    print("--- Pruebas del módulo operaciones ---")
    print("sumar(8, 3) ->", sumar(8, 3))
    print("restar(8, 3) ->", restar(8, 3))
    print("multiplicar(8, 3) ->", multiplicar(8, 3))
    print("dividir(8, 3) ->", round(dividir(8, 3), 2))
    print("dividir(8, 0) ->", dividir(8, 0))

Programa principal que usa el módulo 'operaciones'.

Ejercicio 13: Módulo de conversión de unidades

Enunciado: Crea un módulo conversiones.py con tres funciones: metros_a_pies(metros), pies_a_metros(pies) (la conversión inversa) y kilometros_a_millas(kilometros). Módulo conversiones.py:

"""
Módulo de conversión de unidades.

Contiene funciones para convertir distancias entre metros, pies y
kilómetros/millas.
"""

METROS_A_PIES = 3.28084
KM_A_MILLAS = 0.621371

def metros_a_pies(metros):
    """Convierte una distancia de metros a pies."""
    return metros * METROS_A_PIES


def pies_a_metros(pies):
    """Convierte una distancia de pies a metros."""
    return pies / METROS_A_PIES


def kilometros_a_millas(kilometros):
    """Convierte una distancia de kilómetros a millas."""
    return kilometros * KM_A_MILLAS


if __name__ == "__main__":
    print("--- Pruebas del módulo conversiones ---")
    print("metros_a_pies(10) ->", round(metros_a_pies(10), 2))
    print("pies_a_metros(32.8084) ->", round(pies_a_metros(32.8084), 2))
    print("kilometros_a_millas(42) ->", round(kilometros_a_millas(42), 2))

Suma recursiva de los números pares hasta n.

Módulo con una función recursiva que calcula la suma de todos los números
pares entre 0 y n (ambos incluidos).
"""

def suma_pares_recursivo(n):
    """Calcula la suma de los números pares entre 0 y n, de forma
    recursiva.

    Parámetros:
        n (int): número entero no negativo (límite superior).
    Devuelve:
        int: la suma de todos los números pares entre 0 y n.

        return 0

        return suma_pares_recursivo(n - 1)
    return n + suma_pares_recursivo(n - 2)        # caso recursivo (n par)

"""
Cálculo recursivo del interés compuesto.

Módulo con una función recursiva que calcula el capital final tras aplicar
un interés compuesto durante un número determinado de años.
"""

def interes_compuesto_recursivo(capital, tasa, anios):
    """Calcula el capital final tras aplicar un interés compuesto anual
    durante un número de años, de forma recursiva.

    Parámetros:
        capital (float): capital inicial.
        tasa (float): tasa de interés anual, en tanto por uno (por
            ejemplo, 0.05 para un 5 %).

    return interes_compuesto_recursivo(capital * (1 + tasa), tasa, anios - 1)  # caso recursivo

Ejercicio 30: Contador recursivo de ocurrencias de un dígito

Enunciado: Codifica una función recursiva contar_ocurrencias_digito_recursivo(numero, digito) que cuente cuántas veces aparece un dígito concreto dentro de un número entero positivo.

"""
Contador recursivo de ocurrencias de un dígito.

Módulo con una función recursiva que cuenta cuántas veces aparece un
dígito concreto dentro de un número entero positivo.
"""

def contar_ocurrencias_digito_recursivo(numero, digito):
    """Cuenta cuántas veces aparece un dígito dentro de un número, de
    forma recursiva.

    Parámetros:
        numero (int): número entero positivo en el que buscar.
        digito (int): dígito a contar (de 0 a 9).
    Devuelve:
        int: el número de veces que 'digito' aparece en 'numero'.
    """
    if numero == 0:                                                       # caso base
        return 0
    resto_cuenta = contar_ocurrencias_digito_recursivo(numero // 10, digito)  # caso recursivo
    if numero % 10 == digito:
        return 1 + resto_cuenta
    return resto_cuenta


print(contar_ocurrencias_digito_recursivo(55251, 5))   # 3
print(contar_ocurrencias_digito_recursivo(4839, 9))    # 1
print(contar_ocurrencias_digito_recursivo(1234, 7))    # 0

Salida

3
1
0
