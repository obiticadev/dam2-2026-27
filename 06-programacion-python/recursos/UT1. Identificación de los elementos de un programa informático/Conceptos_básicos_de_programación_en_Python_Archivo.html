UT1. Identificación de los elementos de un programa informático

Introducción

Antes de escribir programas complejos es necesario reconocer las piezas básicas con las que se construyen: qué es Python y con qué herramientas se programa en él, cómo se organiza un programa por dentro, qué es una variable, qué tipos de datos existen, qué diferencia hay entre un literal y una constante, cómo se combinan los datos mediante operadores, cómo se convierten unos tipos en otros y cómo se documenta el código mediante comentarios.

Esta unidad de trabajo presenta estos elementos usando Python como lenguaje de referencia, por ser el lenguaje del módulo, aunque los conceptos son extrapolables a cualquier otro lenguaje de programación.

a) ¿Qué es Python? Herramientas y entorno de desarrollo

¿Qué es Python? Python es un lenguaje de programación de propósito general creado por Guido van Rossum y publicado por primera vez en 1991.

Su diseño prioriza la legibilidad del código (una sintaxis limpia, cercana al lenguaje natural, con una fuerte dependencia de la indentación) y la productividad del programador, lo que lo ha convertido en uno de los lenguajes más utilizados en ámbitos muy diversos: desarrollo web (backend), ciencia de datos e inteligencia artificial, automatización y scripting, desarrollo de aplicaciones de escritorio, testing, o como lenguaje introductorio en la enseñanza de la programación.

¿Qué tipo de lenguaje de programación es Python? Se puede clasificar según varios criterios:

Criterio de clasificaciónPython es...Significado
Según su nivel de abstracciónDe alto nivelSu sintaxis está pensada para ser entendida por personas, alejada del lenguaje máquina; el propio intérprete se encarga de traducirla.
Según cómo se ejecutaInterpretadoEl código fuente no se traduce por completo a lenguaje máquina antes de ejecutarse (como ocurre con un lenguaje compilado, por ejemplo C); un programa llamado intérprete (CPython, la implementación de referencia) va leyendo y ejecutando el código línea a línea en el momento de la ejecución. Esto facilita probar y depurar código rápidamente, a cambio de una ejecución algo más lenta que la de un lenguaje compilado.

Fuerte: Python no realiza conversiones automáticas "arriesgadas" entre tipos incompatibles (por ejemplo, "3" + 3 provoca un error en lugar de un resultado inesperado).
Según el paradigma que admiteMultiparadigmaPermite programar de forma imperativa/estructurada, orientada a objetos y, en buena medida, también de forma funcional.
Según la plataformaMultiplataformaUn mismo programa Python puede ejecutarse, sin apenas cambios, en Windows, macOS o Linux, siempre que el sistema disponga de un intérprete de Python instalado.

Herramientas necesarias para programar en Python:

  1. El intérprete de Python: el programa que traduce y ejecuta el código fuente. Se descarga de forma gratuita desde python.org (en Windows conviene marcar la casilla "Add python.exe to PATH" durante la instalación). Este módulo trabaja con Python 3 (no con Python 2, una versión anterior ya obsoleta). Una vez instalado, se puede comprobar la versión disponible desde una terminal con el comando python --version (o python3 --version en algunos sistemas Linux/macOS).
  2. Un gestor de paquetes: pip, que se instala junto con Python, permite instalar librerías adicionales no incluidas en la instalación básica (por ejemplo, pip install nombre_libreria).
  3. Un editor de código o un IDE: aunque Python incluye un editor muy básico (IDLE), lo habitual es programar con un entorno integrado de desarrollo (IDE) más completo, como Visual Studio Code o PyCharm, que añaden autocompletado, depurador, gestión de proyectos y control de versiones.
  4. Una terminal (línea de comandos): para ejecutar el intérprete, instalar paquetes con pip y lanzar los programas escritos; la mayoría de los IDE, incluido Visual Studio Code, incorporan una terminal integrada, por lo que no es necesario salir del propio editor.
  5. (Opcional pero recomendable a medida que los proyectos crecen) Entornos virtuales (venv): una copia aislada del intérprete y de las librerías para cada proyecto, de forma que las dependencias de un proyecto no interfieran con las de otro.

Configuración de Visual Studio Code para desarrollar en Python:

Visual Studio Code (VS Code) es un editor de código gratuito y multiplataforma desarrollado por Microsoft, muy extendido gracias a su ligereza y a su sistema de extensiones. Para dejarlo listo para programar en Python:

  1. Instalar Python desde python.org (ver punto 1 anterior), antes de configurar VS Code, ya que el editor necesita un intérprete instalado en el sistema al que conectarse.
  2. Descargar e instalar Visual Studio Code desde code.visualstudio.com.
  3. Instalar la extensión oficial "Python" (de Microsoft): dentro de VS Code, abrir la vista de Extensiones (icono lateral o Ctrl+Shift+X), buscar "Python" e instalar la extensión oficial. Esta extensión incorpora Pylance (autocompletado inteligente y detección de errores), soporte para el depurador y ejecución de código.
  4. Seleccionar el intérprete de Python: con la paleta de comandos (Ctrl+Shift+P), ejecutar "Python: Select Interpreter" y elegir la versión de Python instalada en el paso 1. VS Code recordará esta elección para cada carpeta de proyecto.
  5. Abrir una carpeta como proyecto: Archivo > Abrir carpeta... (File > Open Folder), seleccionando (o creando antes) la carpeta que contendrá el código fuente. Trabajar siempre desde una carpeta de proyecto, y no con archivos sueltos, facilita organizar el código, los recursos y, más adelante, el entorno virtual.
  6. Crear y ejecutar un archivo Python: crear un nuevo archivo con extensión .py (por ejemplo, main.py) y ejecutarlo con el botón Run (▷, arriba a la derecha) o desde la terminal integrada (Terminal > Nueva terminal) con el comando python main.py.
  7. (Recomendable) Extensiones adicionales: además de Python/Pylance, suelen instalarse extensiones de formateo y estilo de código (por ejemplo, Black Formatter o autopep8), que ayudan a mantener un código ordenado y coherente con las convenciones de Python (PEP 8).

b) Entornos virtuales en Python

¿Qué es un entorno virtual?

Un entorno virtual (virtual environment) es una copia aislada e independiente del intérprete de Python y de sus librerías, asociada a un proyecto concreto. Al trabajar dentro de un entorno virtual, los paquetes que se instalan con pip se guardan únicamente en esa copia aislada, sin afectar ni al Python "global" del sistema ni a los entornos virtuales de otros proyectos.

¿Por qué se necesitan?

A medida que se trabaja en varios proyectos de Python en el mismo ordenador, es habitual que cada uno necesite versiones distintas de una misma librería, o que un proyecto requiera muchas librerías que no tienen sentido instalar de forma permanente en todo el sistema. Sin entornos virtuales, todas esas dependencias se instalarían mezcladas en la misma instalación global de Python, lo que tarde o temprano provoca conflictos de versiones entre proyectos. Un entorno virtual resuelve este problema dando a cada proyecto sus propias dependencias, de forma:

  • Aislada: lo que se instala en un entorno virtual no afecta a otros proyectos ni al sistema.
  • Reproducible: es posible anotar en un archivo (habitualmente requirements.txt) qué librerías exactas necesita el proyecto, para poder recrear el mismo entorno en otro ordenador.
  • Limpia: el Python del sistema operativo permanece con el mínimo de paquetes instalados, reduciendo el riesgo de romper otras herramientas que también dependan de él.

La herramienta venv: Python incluye de serie, desde la versión 3.3, el módulo venv, que permite crear entornos virtuales sin necesidad de instalar nada adicional (existen alternativas, como virtualenv o conda, pero venv es la opción estándar y suficiente para este módulo).

Crear y usar un entorno virtual desde la terminal:

# 1. Crear el entorno virtual (se genera una carpeta, por convenio llamada .venv)
python -m venv .venv

# 2. Activarlo
#    En Windows (símbolo del sistema):
.venv\Scripts\activate
#    En macOS / Linux:
source .venv/bin/activate

# Una vez activado, el prompt de la terminal muestra el nombre del entorno, por ejemplo:
# (.venv) C:\proyectos\ut1_python>

# 3. Instalar librerías: quedan instaladas SOLO dentro de este entorno virtual
pip install requests

# 4. Anotar las dependencias del proyecto en un archivo, para poder reproducirlas
pip freeze > requirements.txt

# 5. Desactivar el entorno virtual cuando se termina de trabajar
deactivate

Crear un nuevo proyecto con su entorno virtual asociado en Visual Studio Code:

  1. Crea (o abre) la carpeta del proyecto en VS Code, tal y como se explicó en el apartado a) (Archivo > Abrir carpeta...).
  2. Abre la terminal integrada (Terminal > Nueva terminal); por defecto se abre ya situada en la carpeta del proyecto.
  3. Crea el entorno virtual con python -m venv .venv. Se creará una carpeta .venv dentro del proyecto, con su propia copia del intérprete.
  4. VS Code suele detectar automáticamente el nuevo entorno y mostrar un aviso ("We noticed a new environment has been created") ofreciendo seleccionarlo. Si no aparece, selecciónalo manualmente con la paleta de comandos (Ctrl+Shift+P) → "Python: Select Interpreter", eligiendo el intérprete que aparece dentro de la carpeta .venv.
  5. A partir de ese momento, cada vez que se abra una nueva terminal integrada en ese proyecto, VS Code activará automáticamente el entorno virtual seleccionado (se reconoce porque el prompt de la terminal muestra (.venv) al principio), y el botón Run ejecutará los archivos .py usando el intérprete de ese entorno.
  6. Cualquier librería que el proyecto necesite se instala entonces con pip install, quedando registrada únicamente en ese entorno virtual.

Trabajar siempre con un entorno virtual por proyecto, desde el principio, es una buena práctica que se dará por hecha en el resto de unidades de este módulo, especialmente cuando empecemos a usar librerías externas.

c) Estructura y bloques fundamentales

Un programa informático es un conjunto ordenado de instrucciones que un ordenador ejecuta para resolver un problema o realizar una tarea. Ese conjunto de instrucciones, escrito en un lenguaje de programación y en un archivo de texto, se denomina código fuente.

Todo programa Python se organiza en una serie de bloques fundamentales:

  1. Cabecera / importaciones: en Python, la zona inicial del archivo donde se importan los módulos y librerías necesarios (import) y, opcionalmente, se indica el intérprete a usar mediante la línea shebang (#!/usr/bin/env python3) en sistemas Unix.
  2. Declaraciones globales: definición de constantes, variables globales o configuración inicial que va a usar el programa.
  3. Definición de funciones y clases: bloques de código reutilizable que encapsulan una tarea concreta (def) o que modelan una entidad mediante programación orientada a objetos (class). Se estudiarán en detalle en futuras unidades de trabajo, de modo que en esta unidad basta con reconocer que ese bloque existe dentro de la estructura de un programa.
  4. Cuerpo principal del programa: la secuencia de instrucciones que se ejecuta cuando se lanza el programa. Es el bloque donde ocurre la lógica central: se preparan o solicitan los datos, se realizan los cálculos y se muestran los resultados. En Python es una práctica profesional muy extendida proteger este cuerpo principal con la construcción if __name__ == "__main__":, que se explica con detalle en el apartado d) de esta unidad.
  5. Punto de entrada y salida: el lugar donde comienza la ejecución (la primera instrucción del cuerpo principal) y donde termina (fin del programa o instrucción de salida explícita, como sys.exit()).

Dentro del cuerpo del programa, las instrucciones se agrupan siguiendo las tres estructuras de control propias de la programación estructurada:

  • Secuencial: las instrucciones se ejecutan una detrás de otra, en el orden en que aparecen.
  • Selectiva o condicional (if / elif / else): el flujo se bifurca según se cumpla o no una condición.
  • Iterativa o repetitiva (for, while): un bloque de instrucciones se repite mientras se cumpla una condición o para cada elemento de una colección.

Estas dos últimas estructuras (selectiva e iterativa) se estudiarán en profundidad en la siguiente unidad de trabajo; en esta unidad basta con saber que existen y que son las responsables de que el flujo del programa no sea siempre una simple secuencia de arriba abajo.

Una particularidad de Python frente a otros lenguajes (Java, C#, C++) es que no delimita los bloques con llaves { }, sino mediante la indentación (sangrado), que no es una cuestión estética sino una regla sintáctica obligatoria: dos instrucciones con distinta indentación pertenecen a bloques distintos.

Ejemplo en Python

#!/usr/bin/env python3
# --- 1. Cabecera / importaciones ---
import math

# --- 2. Declaraciones globales ---
IVA = 0.21          # constante global
precio = 100        # variable global

# --- 3. Definición de funciones y clases ---
# (todavía no se implementa: las funciones y las clases se estudiarán
#  en las siguientes unidades; por ahora el cálculo se hace directamente
#  en el cuerpo principal del programa)

# --- 4. Cuerpo principal del programa ---
precio_final = precio * (1 + IVA)          # estructura secuencial
print("Precio final:", precio_final)
# (aquí se ubicarían más adelante las estructuras selectivas -if-
#  e iterativas -for/while-, que se estudiarán más adelante)

# --- 5. Punto de entrada y salida ---
# La ejecución de este programa comienza en la línea "precio_final = ..."
# (primera instrucción del cuerpo principal) y termina al llegar
# a la última línea del archivo.

d) Ejecución de un programa: script frente a módulo

En el apartado anterior se ha visto que el cuerpo principal de un programa suele protegerse con la construcción if __name__ == "__main__":. Este apartado desarrolla en detalle qué significa esto y por qué es una práctica tan extendida entre programadores profesionales.

Un mismo archivo .py se puede usar de dos formas distintas:

  • Como script ejecutable: se lanza directamente, por ejemplo escribiendo python main.py en la terminal o pulsando el botón Run del IDE, para que realice su tarea de principio a fin.
  • Como módulo importable: otro archivo Python lo incorpora mediante import, para reutilizar las funciones, clases o datos que contiene, sin necesidad de copiar su código.

Para que Python sepa distinguir en qué "modo" se está usando un archivo en cada momento, asigna automáticamente a todo archivo .py una variable interna llamada __name__, cuyo valor depende de cómo se está ejecutando ese archivo:

¿Cómo se usa el archivo?Valor de __name__ dentro de ese archivo
Se ejecuta directamente (python main.py, o Run en el IDE)"__main__"
Se importa desde otro archivo (por ejemplo, import main)El nombre del propio archivo, como texto ("main")

Gracias a esta diferencia, comprobar if __name__ == "__main__": y colocar dentro de ese bloque el cuerpo principal del programa hace que dicho código solo se ejecute cuando el archivo se lanza directamente, y no cuando otro programa lo importa únicamente para reutilizar sus funciones o clases. De este modo, un mismo archivo puede funcionar a la vez como programa ejecutable y como módulo reutilizable, sin que al importarlo se disparen sus acciones por accidente (por ejemplo, mostrar mensajes por pantalla, pedir datos al usuario o realizar cálculos que solo tenían sentido al ejecutarlo directamente).

Esta construcción utiliza una estructura selectiva (if), contenido que se estudiará formalmente en la siguiente unidad de trabajo. Por ese motivo, en esta unidad no se pide todavía escribir el if __name__ == "__main__": en las actividades: basta con comprobar, mediante print(), el valor que toma __name__ en cada situación, y con saber identificar en qué parte del código se colocaría esa protección en el futuro.

Ejemplo en Python

Programa saludo.py, pensado para observar el valor de __name__ según cómo se ejecute:

# --- saludo.py ---
print("Valor de __name__ en este archivo:", __name__)
print("Hola desde saludo.py")

Si este archivo se ejecuta directamente (python saludo.py), el resultado en pantalla es:

Valor de __name__ en este archivo: __main__
Hola desde saludo.py

Si, en cambio, se crea un segundo archivo principal.py en la misma carpeta que importa al anterior...

# --- principal.py ---
import saludo

print("Esto se ejecuta desde principal.py")

... y se ejecuta principal.py, el resultado es:

Valor de __name__ en este archivo: saludo
Hola desde saludo.py
Esto se ejecuta desde principal.py

Obsérvese que, al importar saludo, su código se ejecuta igualmente (se muestran sus dos mensajes), pero esta vez __name__ vale "saludo" en lugar de "__main__". Es precisamente este comportamiento el que la construcción if __name__ == "__main__": permite controlar: envolviendo con ella las instrucciones de saludo.py, estas solo se ejecutarían al lanzar ese archivo directamente, y no al importarlo desde principal.py. Así quedaría, a modo de comentario, sin necesidad de escribirla todavía como código funcional:

# --- saludo.py ---
print("Valor de __name__ en este archivo:", __name__)

# A partir de la siguiente unidad de trabajo, cuando se estudien las estructuras selectivas,
# el siguiente mensaje se protegería así para que NO se repita al
# importar este archivo desde otro programa:
#
#     if __name__ == "__main__":
#         print("Hola desde saludo.py")

e) Variables

Una variable es un espacio de memoria identificado por un nombre (identificador) que almacena un valor susceptible de cambiar durante la ejecución del programa. Toda variable tiene tres elementos: un nombre, un valor y, de forma asociada al valor, un tipo de dato.

En Python las variables se crean en el momento en que se les asigna un valor por primera vez (no es necesario declararlas previamente como en otros lenguajes), mediante el operador de asignación =:

edad = 17
nombre = "Laura"

Python es un lenguaje de tipado dinámico: no hace falta indicar el tipo al declarar la variable (el intérprete lo deduce del valor asignado) y, además, una misma variable puede cambiar de tipo si se le asigna un valor de otro tipo en otro punto del programa.

Reglas para nombrar variables (identificadores) en Python:

  • Pueden contener letras, números y guion bajo (_), pero no pueden empezar por un número.
  • Distinguen mayúsculas de minúsculas (edad y Edad son variables distintas).
  • No pueden coincidir con una palabra reservada del lenguaje (if, for, class, import...).
  • Por convenio (PEP 8), se escriben en minúsculas con guion bajo entre palabras (snake_case): nombre_completo, precio_final.

Tipos de variables según su ámbito (utilidad específica de cada una):

Tipo de variableDónde se defineUtilidad
LocalDentro de una funciónSolo existe y es accesible mientras se ejecuta esa función; evita interferencias entre distintas partes del programa.
GlobalFuera de cualquier función, a nivel de móduloAccesible desde cualquier punto del programa; útil para configuración o datos compartidos, aunque su abuso dificulta el mantenimiento del código.
De instancia / atributoDentro de una clase, asociada a selfAlmacena el estado propio de cada objeto creado a partir de esa clase (programación orientada a objetos).
De parámetroEn la cabecera de una funciónRecibe el valor con el que se invoca la función y solo vive durante esa llamada.

Las variables locales y de parámetro solo pueden practicarse de forma completa a partir de la unidad de trabajado correspondiente al estudio de las funciones y las variables de instancia a partir de la unidad de trabajo correspondiente a la programación orientada a objetos; esta unidad se centra en las variables globales, definidas directamente en el cuerpo principal del programa.

Ejemplo en Python

nombre = "Laura"      # variable global, creada al asignarle un valor por primera vez
edad = 17

print(nombre, edad)

edad = edad + 1        # se modifica el valor de la variable 'edad'
print(edad)             # 18

nombre = "Laura García"   # una misma variable puede recibir un nuevo valor en cualquier momento
print(nombre)

g) Entrada de datos por teclado: la función input()

¿Qué es input()?

Es una función incorporada (built-in) del lenguaje, disponible siempre, sin necesidad de importar ningún módulo. Su finalidad es permitir que un programa se detenga durante su ejecución y quede a la espera de que la persona que lo está usando escriba algo por teclado.

¿Para qué sirve?

Hasta ahora, los programas de esta unidad han trabajado siempre con los mismos datos fijos, escritos directamente en el código (literales). Gracias a input(), un programa puede interactuar con quien lo ejecuta y trabajar con datos que cambian cada vez: su nombre, una cantidad, una respuesta... Es la forma más sencilla de hacer que un programa sea interactivo en lugar de repetir siempre el mismo resultado.

¿Cómo funciona?

El funcionamiento de input() sigue siempre estos pasos:

  1. Se invoca input(), opcionalmente con un texto entre paréntesis: ese texto es el mensaje o prompt que se muestra en pantalla para indicar a la persona usuaria qué se espera que escriba (por ejemplo, input("¿Cómo te llamas? ")).
  2. La ejecución del programa se detiene en esa línea, esperando a que el usuario escriba algo y pulse la tecla Intro.
  3. Todo lo que el usuario ha escrito (sin incluir el salto de línea de Intro) se devuelve como resultado de la función, y habitualmente se guarda en una variable mediante = para poder usarlo después.
  4. Detalle fundamental: input() siempre devuelve el dato como una cadena de texto (str), sin importar lo que la persona usuaria haya escrito, aunque solo haya tecleado dígitos. Si el dato introducido se necesita como número para hacer cálculos con él, habrá que convertirlo explícitamente; esto se estudiará con detalle en el apartado k) Conversiones de tipo de esta misma unidad.

Ejemplo en Python

nombre = input("¿Cómo te llamas? ")
print("Hola,", nombre)

edad_texto = input("¿Qué edad tienes? ")
print("Has escrito:", edad_texto)
print("El tipo de dato que ha devuelto input() es:", type(edad_texto))
# El tipo de dato que ha devuelto input() es: <class 'str'>
# (aunque se haya introducido, por ejemplo, "17")

h) Literales

Un literal es la representación fija y directa de un valor tal y como se escribe en el código fuente, sin necesidad de calcularlo ni de asignarlo previamente a una variable. Es, dicho de otro modo, el "valor tal cual" que aparece escrito en el programa.

Cada tipo de dato tiene su propia forma de expresarse como literal en Python:

Entero en otras bases0b1010 (binario), 0o17 (octal), 0x1F (hexadecimal)
Real (flotante)3.14, -0.5, 2.5e3 (notación científica)
Cadena de texto"hola", 'hola', """texto multilínea"""
BooleanoTrue, False
Lista[1, 2, 3]
Tupla(1, 2, 3)
Diccionario{"clave": "valor"}
NuloNone

Es importante no confundir un literal con una variable: en la instrucción edad = 17, 17 es el literal (el valor fijo escrito directamente) y edad es la variable que lo almacena.

i) Constantes

Una constante es un valor con nombre que, a diferencia de una variable, no debe cambiar durante la ejecución del programa. Se usan para valores fijos y significativos que aparecen varias veces en el código (el número π, el IVA, el número máximo de intentos permitidos, una ruta de configuración, etc.), evitando así los llamados "números mágicos" y facilitando el mantenimiento: si el valor cambia, solo hay que modificarlo en un sitio.

Python no dispone de una palabra reservada específica para declarar constantes (a diferencia de final en Java o const en C++ o JavaScript). Se trata, por tanto, de una convención: se declaran como variables normales, pero su nombre se escribe en mayúsculas con guiones bajos (SNAKE_CASE en mayúsculas), indicando a quien lea el código que ese valor no debe reasignarse:

PI = 3.14159
IVA = 0.21
MAX_INTENTOS = 3

Aunque el intérprete no impide técnicamente reasignar una "constante" en Python, buenas prácticas y herramientas de análisis de código (linters) alertan de ello. Cuando se necesita una constante realmente inmutable a nivel de lenguaje, puede recurrirse al módulo enum o, desde Python 3.8, a typing.Final como anotación de intención.

Ejemplo en Python

PI = 3.14159
IVA = 0.21

radio = 4
area = PI * radio ** 2
print(area)

precio_base = 50
precio_final = precio_base * (1 + IVA)
print(precio_final)

j) Operadores y expresiones

Una expresión es una combinación de literales, variables, constantes y operadores que el intérprete evalúa para producir un valor. Los operadores son los símbolos que indican qué operación debe realizarse sobre uno o varios operandos. Se clasifican en:

1. Operadores aritméticos — realizan cálculos numéricos:

OperadorSignificadoEjemploResultado
+Suma5 + 27
-Resta5 - 23
*Multiplicación5 * 210
/División (siempre devuelve float)5 / 22.5
//División entera5 // 22
%Módulo (resto)5 % 21
**Potencia5 ** 225

2. Operadores relacionales o de comparación — comparan dos valores y devuelven un bool:

== (igual a), != (distinto de), > (mayor que), < (menor que), >= (mayor o igual), <= (menor o igual).

3. Operadores lógicos — combinan expresiones booleanas: and, or, not.

4. Operadores de asignación — asignan (y opcionalmente calculan) un valor: =, +=, -=, *=, /=, //=, %=, **=.

5. Operadores de identidad y pertenencia (propios de Python): is / is not (comparan si dos referencias apuntan al mismo objeto en memoria) y in / not in (comprueban si un valor pertenece a una colección).

Precedencia de operadores: cuando una expresión combina varios operadores, Python los evalúa siguiendo un orden de prioridad (potencia, luego multiplicación/división, luego suma/resta, luego comparaciones, luego operadores lógicos), que puede alterarse mediante paréntesis ().

k) Conversiones de tipo

Una conversión de tipo consiste en transformar un valor de un tipo de dato en otro. En Python existen dos formas de conversión:

  • Conversión implícita (coerción automática): el propio intérprete convierte un tipo en otro de forma automática cuando una operación combina tipos compatibles, sin que el programador lo solicite expresamente. Suele producirse al mezclar int y float en una operación aritmética, en cuyo caso el resultado se "amplía" al tipo más general (float) para no perder información.
  • Conversión explícita (casting): el programador solicita expresamente la conversión mediante una función de conversión: int(), float(), str(), bool(), list(), tuple(), set(), etc.

l) Comentarios

Un comentario es un fragmento de texto incluido en el código fuente que el intérprete ignora por completo durante la ejecución. Su finalidad es exclusivamente documentar el programa: explicar qué hace una parte del código, por qué se ha tomado una decisión concreta, dejar pendientes (TODO) o facilitar que otra persona —o uno mismo en el futuro— entienda el programa sin tener que descifrar cada línea.

En Python existen dos formas de comentar código:

  • Comentario de una línea: comienza por el símbolo almohadilla #. Todo lo que sigue en esa línea es ignorado por el intérprete.
  • Comentario multilínea / docstring: se delimita con triple comilla ("""...""" o '''...'''). Aunque técnicamente es una cadena de texto (no un comentario "puro" del lenguaje), si no se asigna a ninguna variable ni se usa su valor, el intérprete la evalúa y descarta, funcionando en la práctica como un comentario de varias líneas. Cuando esta cadena triple se coloca justo debajo de la definición de un módulo, función, clase o método, se denomina docstring y sirve para documentar automáticamente ese elemento (accesible mediante help() o el atributo __doc__).

Buenas prácticas al comentar código:

  • Comentar el por qué de una decisión, no simplemente repetir lo que el código ya dice de forma evidente.
  • Mantener los comentarios actualizados: un comentario que no coincide con el código que describe es peor que no tener comentario.
  • Usar docstrings para documentar módulos, funciones y clases.
  • No abusar de los comentarios hasta el punto de saturar la lectura del código.
