UT2. Uso de estructuras de control. Tratamiento de excepciones

Introducción

En la unidad anterior se identificaron los elementos básicos de un programa (variables, tipos de datos, operadores...). Con esos elementos ya es posible construir expresiones y realizar cálculos, pero un programa útil necesita además decidir qué camino seguir según una condición, repetir tareas varias veces y reaccionar ante situaciones inesperadas durante la ejecución. De eso se ocupan las estructuras de control: instrucciones que alteran el orden secuencial por defecto en que se ejecutan las sentencias de un programa.

Esta unidad de trabajo desarrolla las cuatro grandes familias de estructuras de control en Python: de selección, de repetición, de salto y de control de excepciones, combinando teoría, ejemplos y actividades prácticas de escritura, prueba y depuración de código.

a) Estructuras de selección

Las estructuras de selección (también llamadas condicionales o de decisión) permiten que el programa ejecute uno u otro bloque de instrucciones en función de si se cumple o no una condición, es decir, del resultado de evaluar una expresión booleana (True o False).

1. Selección simple — if

Ejecuta un bloque de código solo si la condición es verdadera:

edad = 20
if edad >= 18:
    print("Eres mayor de edad")

2. Selección doble — if / else

Ofrece un camino alternativo cuando la condición es falsa:

edad = 15
if edad >= 18:
    print("Eres mayor de edad")
else:
    print("Eres menor de edad")

3. Selección múltiple — if / elif / else

Permite encadenar varias condiciones excluyentes entre sí; se evalúan en orden y se ejecuta el primer bloque cuya condición sea verdadera:

nota = 6
if nota >= 9:
    calificacion = "Sobresaliente"
elif nota >= 7:
    calificacion = "Notable"
elif nota >= 5:
    calificacion = "Aprobado"
else:
    calificacion = "Suspenso"
print(calificacion)

4. Selección anidada

Una estructura if puede colocarse dentro de otra, para evaluar condiciones dependientes entre sí. Debe usarse con moderación, ya que un anidamiento excesivo dificulta la lectura del código.

5. Expresión condicional (operador ternario)

Python permite escribir una selección simple/doble en una sola línea, útil para asignaciones breves: 

edad = 17
estado = "adulto" if edad >= 18 else "menor"

6. Selección por coincidencia de patrones — match / case (desde Python 3.10)

Alternativa al encadenamiento de varios if/elif cuando se comparan los posibles valores de una misma variable, similar al switch de otros lenguajes:

dia = 3
match dia:
    case 1 | 7:
        print("Fin de semana")
    case 2 | 3 | 4 | 5 | 6:
        print("Día laborable")
    case _:
        print("Día no válido")   # 'case _' es el caso por defecto

Es fundamental recordar que en Python los bloques de cada rama se delimitan mediante indentación, no con llaves, y que la condición del if debe terminar siempre con dos puntos (:).

Ejemplo en Python

peso = 70
altura = 1.75
imc = peso / altura ** 2

if imc < 18.5:
    print("Bajo peso")
elif imc < 25:
    print("Peso normal")
elif imc < 30:
    print("Sobrepeso")
else:
    print("Obesidad")

b) Estructuras de repetición

Las estructuras de repetición (o bucles) permiten ejecutar un mismo bloque de instrucciones varias veces, evitando repetir código de forma manual. Python dispone de dos sentencias de repetición:

1. Bucle while (repetición controlada por condición)

Repite el bloque de código mientras una condición se mantenga verdadera. La condición se comprueba antes de cada repetición, por lo que el bloque puede no ejecutarse ni una sola vez si la condición es falsa desde el principio. Se utiliza cuando no se sabe de antemano cuántas veces hay que repetir el bloque.

contador = 0
while contador < 5:
    print("Repetición", contador)
    contador += 1     # imprescindible actualizar la condición para evitar un bucle infinito

2. Bucle for (repetición controlada por recorrido)

Recorre los elementos de una secuencia (cadena, lista, tupla, diccionario...) o de un objeto iterable, ejecutando el bloque una vez por cada elemento. Se utiliza cuando sí se conoce la colección o el número de repeticiones.

for letra in "DAM":
    print(letra)

for elemento in [10, 20, 30]:
    print(elemento)

La función range() genera una secuencia de números y se combina muy a menudo con for para repetir un bloque un número determinado de veces:

for i in range(5):        # 0, 1, 2, 3, 4
    print(i)

for i in range(2, 10, 2): # de 2 a 8, de 2 en 2: 2, 4, 6, 8
    print(i)

Bucles anidados: un bucle puede contener otro bucle en su interior, muy habitual al recorrer estructuras bidimensionales (por ejemplo, una tabla o matriz).

Elección entre while y for: como regla general, se usa for cuando se recorre una colección conocida o un rango de valores, y while cuando la repetición depende de una condición que puede cambiar de forma impredecible en tiempo de ejecución (por ejemplo, hasta que el usuario introduzca un dato válido).

Ejemplo en Python

numero = 7
for i in range(1, 11):
    print(numero, "x", i, "=", numero * i)

# while: repetición hasta que el usuario introduce un valor válido
intentos = 0
MAX_INTENTOS = 3
clave_correcta = "1234"
coincide = False
while intentos < MAX_INTENTOS and not coincide:
    clave = input("Introduce la clave: ")
    if clave == clave_correcta:
        coincide = True
        print("Acceso concedido")
    intentos += 1

if not coincide:
    print("Acceso denegado: máximo de intentos alcanzado")

c) Estructuras de salto

Las sentencias de salto alteran el flujo normal de una estructura de repetición o de una función, "saltando" a otro punto del programa antes de que dicha estructura termine de forma natural. Python incorpora las siguientes:

Sentencia Efecto
break Termina inmediatamente el bucle (for o while) en el que se encuentra, saltando a la primera instrucción posterior al bucle.
continue Interrumpe la iteración actual del bucle y salta directamente a la siguiente repetición, sin ejecutar el resto de instrucciones de esa vuelta.
pass No hace absolutamente nada; es una instrucción "vacía" que se usa como marcador de posición allí donde la sintaxis exige una instrucción (por ejemplo, en una función o un bloque if aún sin implementar).
return Finaliza la ejecución de una función y, opcionalmente, devuelve un valor al punto donde se la llamó. Como solo tiene sentido dentro de una función, su uso práctico se retomará en la siguiente, junto con la definición de funciones.
sys.exit() Finaliza la ejecución de todo el programa (requiere import sys).

Una particularidad de Python es la cláusula else asociada a un bucle (for...else / while...else, ya usada en el ejemplo del apartado b): el bloque else se ejecuta únicamente si el bucle ha terminado de forma natural, es decir, si no se ha interrumpido con break. Esto resulta muy útil para distinguir, por ejemplo, entre "se ha encontrado el elemento buscado" (se sale con break) y "se ha recorrido toda la colección sin encontrarlo" (el bucle termina solo y se ejecuta el else).

Ejemplo en Python

# while: repetición hasta que el usuario introduce un valor válido
intentos = 0
MAX_INTENTOS = 3
clave_correcta = "1234"
while intentos < MAX_INTENTOS:
    clave = input("Introduce la clave: ")
    if clave == clave_correcta:
        print("Acceso concedido")
        break
    intentos += 1
else:
    print("Acceso denegado: máximo de intentos alcanzado")

# pass: instrucción vacía, usada como marcador de posición
respuesta = input("¿Aplicar descuento especial? (s/n): ")
if respuesta == "s":
    pass   # TODO: implementar el cálculo del descuento más adelante
else:
    print("Sin descuento")

d) Control de excepciones

Una excepción es un error que se produce durante la ejecución de un programa (a diferencia de los errores de sintaxis, que impiden incluso que el programa llegue a ejecutarse) y que, si no se gestiona, provoca que el programa termine de forma abrupta mostrando un mensaje de error (traceback). Ejemplos típicos: dividir entre cero, convertir a int un texto no numérico, acceder a un índice de lista que no existe, o intentar abrir un archivo que no existe.

El control de excepciones consiste en anticipar esos posibles errores y decidir cómo debe reaccionar el programa, en lugar de dejar que se detenga de forma descontrolada. Python gestiona las excepciones mediante el bloque try / except:

try:
    numero = int(input("Introduce un número: "))
    resultado = 10 / numero
except ValueError:
    print("Eso no es un número válido")
except ZeroDivisionError:
    print("No se puede dividir entre cero")
else:
    print("Resultado:", resultado)
finally:
    print("Fin del programa")
  • try: contiene el bloque de código que puede provocar una excepción.
  • except: contiene el bloque que se ejecuta solo si se produce la excepción indicada. Puede haber varios bloques except, cada uno para un tipo de excepción distinto, lo que permite dar una respuesta específica a cada error.
  • else (opcional): se ejecuta únicamente si el bloque try no ha producido ninguna excepción.
  • finally (opcional): se ejecuta siempre, se haya producido o no una excepción; se usa habitualmente para tareas de limpieza (cerrar un archivo, liberar una conexión...).

Algunas excepciones habituales (jerarquía de la clase Exception):

Excepción Se produce cuando...
ValueError Un valor tiene el tipo correcto pero no es válido (int("hola"))
TypeError Se opera con tipos incompatibles ("5" + 5)
ZeroDivisionError Se divide entre cero
IndexError Se accede a un índice de lista/tupla que no existe
KeyError Se accede a una clave de diccionario que no existe
FileNotFoundError Se intenta abrir un archivo que no existe
AttributeError Se accede a un atributo o método que no existe en un objeto

Lanzar excepciones propias: además de capturarlas, un programa puede provocar una excepción de forma deliberada con la sentencia raise, por ejemplo para validar los datos de entrada de una función:

edad = -5

try:
    if edad < 0:
        raise ValueError("La edad no puede ser negativa")
except ValueError as error:
    print("Error:", error)

(En la siguiente unidad, al estudiar las funciones, este mismo raise se colocará dentro de una función establecer_edad(edad), que es su ubicación más habitual.)

Capturar excepciones de forma demasiado genérica (except: a secas, o except Exception:) suele considerarse una mala práctica, ya que oculta errores inesperados y dificulta la depuración; siempre que sea posible, es preferible capturar el tipo de excepción concreto que se espera.

Ejemplo en Python

# División segura, controlando la división entre cero
a, b = 10, 0
try:
    resultado = a / b
except ZeroDivisionError:
    print("Error: no se puede dividir entre cero")
    resultado = None
print(resultado)

# Bucle que repite la petición hasta que el usuario introduce un entero válido
while True:
    try:
        edad = int(input("Introduce tu edad: "))
        if edad < 0:
            raise ValueError("La edad no puede ser negativa")
        break
    except ValueError as error:
        print("Entrada no válida:", error, "- Inténtalo de nuevo.")

print("Tu edad es", edad)

(En la siguiente unidad se reorganizarán estos dos bloques como funciones dividir_seguro(a, b) y leer_edad(), reutilizables desde cualquier parte de un programa.)

e) Prueba y depuración del código

Escribir código con estructuras de control no es suficiente: programar exige también probar y depurar los programas, es decir, comprobar que funcionan correctamente para distintos casos (incluidos los casos límite) y localizar y corregir los errores que aparezcan. Algunas técnicas básicas:

  • Depuración mediante print(): la forma más sencilla de inspeccionar el valor de una variable o el punto del programa al que se ha llegado, insertando temporalmente instrucciones print() de control.
  • Depurador del IDE (debugger): herramienta integrada en PyCharm o VS Code que permite colocar puntos de interrupción (breakpoints), ejecutar el programa paso a paso (step over / step into) y examinar en cada momento el valor de todas las variables, mucho más eficaz que ir añadiendo y quitando print().
  • Prueba con distintos casos de entrada: comprobar el comportamiento del programa no solo con datos "normales", sino también con los llamados casos límite (valores extremos, cero, negativos, cadenas vacías, entradas no numéricas...), que son precisamente los que suelen poner a prueba las estructuras de selección, repetición y control de excepciones.
  • Comentarios y documentación: como ya se trabajó en la unidad anterior, comentar (#) y documentar (docstrings) el código ayuda tanto a quien lo lee como al propio programador durante la depuración, dejando constancia de qué se esperaba que hiciera cada bloque.
