<Quiz id="sge-v1-ut2-siglas-integracion-01">
¿Qué significa SGBD y qué aporta a un ERP?

- [x] Sistema gestor de bases de datos: persistencia e integridad.
  > Correcta. El SGBD almacena y administra datos. PostgreSQL, SQL Server, Oracle Database y SAP HANA son ejemplos; hay que comprobar compatibilidad con producto y versión.
- [ ] Servicio general de búsqueda documental: campañas comerciales.
  > Un SGBD no se define como una herramienta de marketing ni solo de búsqueda documental.
- [ ] Sistema global de balance diario: diseño de productos.
  > No es el desarrollo de SGBD y el diseño pertenece a otras herramientas.
- [ ] Servidor gráfico de botones digitales: apariencia de la web.
  > El aspecto visual no es la finalidad del gestor de bases de datos.

<Quiz id="sge-v1-ut2-siglas-integracion-02">
¿Qué significa ORM y qué conecta?

- [ ] Order Resource Management: clientes y campañas.
  > No es el desarrollo de ORM en el acceso a datos del ERP.
- [x] Object-Relational Mapping: objetos y datos relacionales.
  > Correcta. El mapeo objeto-relacional permite trabajar desde objetos de la aplicación con información de una base relacional, dentro de la capa de persistencia.
- [ ] Online Report Monitor: pantallas y colores.
  > Un monitor de informes no describe el mapeo entre objetos y tablas.
- [ ] Operational Risk Model: seguros y proveedores.
  > El análisis de riesgo es otro concepto; ORM aquí se refiere a persistencia.

<Quiz id="sge-v1-ut2-siglas-integracion-03">
¿Por qué puede ser peligroso modificar directamente con SQL las tablas de un ERP?

- [ ] Porque SQL solo permite cambiar colores de una pantalla.
  > SQL trabaja con datos, no se limita a la presentación visual.
- [ ] Porque cualquier modificación SQL crea un cliente nuevo.
  > El efecto depende de la instrucción y del modelo; no hay ese comportamiento universal.
- [x] Puede saltarse reglas de negocio y romper coherencia.
  > Correcta. SQL —Structured Query Language, lenguaje de consulta estructurada— opera sobre datos. El ERP puede validar y coordinar operaciones desde su lógica de aplicación; saltarla entraña riesgos.
- [ ] Porque una base relacional nunca admite actualizaciones.
  > Las bases relacionales sí admiten cambios; el riesgo está en eludir controles y relaciones del ERP.

¿Qué describe una integración mediante API REST con JSON?

- [ ] Un diseño 3D que controla directamente una fresadora.
  > El diseño y el mecanizado se relacionan con CAD, CAM y CNC.
- [ ] Un modelo que calcula la cantidad económica de pedido.
  > Ese cálculo corresponde a EOQ, no a la interfaz de integración.
- [ ] Un cuestionario que mide la recomendación del cliente.
  > La recomendación se asocia al NPS; no define API, REST ni JSON.
- [x] Aplicaciones que intercambian datos por una interfaz.
  > Correcta. API es Application Programming Interface; REST, Representational State Transfer, es un estilo de arquitectura. JSON —JavaScript Object Notation— es un formato de intercambio de datos.

<Quiz id="sge-v1-ut2-siglas-integracion-05">
¿Qué asociación es correcta en una integración empresarial?

- [x] SOAP: protocolo de mensajes; XML: formato estructurado.
  > Correcta. SOAP se desarrolla habitualmente como Simple Object Access Protocol. XML es eXtensible Markup Language, lenguaje de marcado extensible; el tema los cita como vía de integración.
- [ ] SOAP: dimensión temporal; XML: medida de ventas.
  > No son elementos de un modelo multidimensional.
- [ ] SOAP: módulo de nóminas; XML: proveedor de nube.
  > Un protocolo y un lenguaje de marcado no son esos productos o módulos.
- [ ] SOAP: indicador de bajas; XML: índice de recomendación.
  > Las bajas se asocian a churn y la recomendación a NPS, no a SOAP/XML.

¿Para qué se utilizan ODBC y JDBC?

- [ ] Para modelar piezas y generar instrucciones de mecanizado.
  > Esas tareas se relacionan con CAD y CAM.
- [x] Para conectar aplicaciones con bases de datos.
  > Correcta. ODBC es Open Database Connectivity; JDBC es Java Database Connectivity, la API de conectividad de Java con bases de datos. No garantizan compatibilidad con cualquier ERP sin configuración.
- [ ] Para segmentar clientes según sus preferencias comerciales.
  > La segmentación es analítica; los conectores pueden aportar acceso a datos, pero no realizan esa tarea por definición.
- [ ] Para definir misión, visión y razón de ser de la empresa.
  > Son conceptos de planificación, no de conectividad técnica.

<Quiz id="sge-v1-ut2-siglas-integracion-07">
¿Qué papel pueden tener archivos CSV o Excel en una arquitectura BI?

- [ ] Garantizar automáticamente que no existen datos duplicados.
  > El formato de archivo no garantiza calidad ni unicidad.
- [ ] Sustituir cualquier necesidad de definir indicadores.
  > Los objetivos e indicadores siguen siendo necesarios con independencia de la fuente.
- [x] Ser fuentes que se preparan e integran para analizar.
  > Correcta. CSV significa Comma-Separated Values, valores separados por comas. Los archivos pueden aportar información, pero necesitan validación y coherencia igual que otras fuentes.
- [ ] Impedir por definición cargar información en un DW.
  > Son fuentes que el tema incluye expresamente en la preparación analítica.

<Quiz id="sge-v1-ut2-siglas-integracion-08">
En regresión, ¿qué relación existe entre MSE y RMSE?

- [ ] MSE es el número de clientes y RMSE su dirección.
  > No son atributos de clientes, sino métricas de error.
- [ ] RMSE siempre es el doble del MSE.
  > La relación es raíz cuadrada, no multiplicación por dos.
- [ ] Ambas métricas definen el precio de la licencia del ERP.
  > Evalúan predicciones; no determinan costes comerciales.
- [x] RMSE es la raíz cuadrada del MSE.
  > Correcta. MSE es Mean Squared Error, error cuadrático medio; RMSE es Root Mean Squared Error, su raíz. Se usan para evaluar errores de predicción numérica.

<Quiz id="sge-v1-ut2-siglas-integracion-09">
¿Qué asociación de métricas de regresión es correcta?

- [x] MAE: error absoluto medio; R²: coeficiente de determinación.
  > Correcta. MAE es Mean Absolute Error, media de magnitudes absolutas de error. R² valora el ajuste respecto a una referencia; no son indicadores de satisfacción.
- [ ] MAE: altas de clientes; R²: tasa de recomendación.
  > Altas y recomendación son métricas de clientes, no estas métricas de regresión.
- [ ] MAE: tamaño de la base; R²: memoria del servidor.
  > La capacidad técnica no es el significado de esas medidas.
- [ ] MAE: venta cruzada; R²: aumento de gama del producto.
  > Cross-selling y up-selling son técnicas comerciales distintas de evaluar modelos.

---

<Quiz id="sge-v1-ut2-siglas-integracion-10">
Para detectar fraude, interesa saber qué parte de los fraudes reales se ha detectado. ¿Qué medida expresa eso?

- [ ] Precisión de los casos marcados como fraude.
  > Indica qué parte de los señalados es realmente fraude; no qué parte de todos los fraudes se detecta.
- [x] Recall o exhaustividad.
  > Correcta. Recall compara positivos detectados con todos los positivos reales. Precisión compara aciertos positivos con positivos predichos; F1 combina ambas y la matriz de confusión resume aciertos y errores por clase.
- [ ] Número total de columnas del archivo analizado.
  > La estructura del archivo no mide la detección de positivos reales.
- [ ] Precio de la suscripción a la plataforma analítica.
  > Un coste no indica la calidad de la detección.

<Quiz id="sge-v1-ut2-siglas-integracion-11">
¿Qué distingue exactitud global de precisión en clasificación?

- [ ] Ambas miden siempre únicamente el coste del entrenamiento.
  > Son métricas de predicción, no importes económicos.
- [ ] Exactitud solo cuenta falsos positivos; precisión, filas vacías.
  > Ninguna definición coincide con sus fórmulas ni finalidades.
- [x] Exactitud cuenta aciertos globales; precisión, aciertos positivos.
  > Correcta. Accuracy o exactitud es la proporción total de predicciones acertadas. Precision o precisión considera los positivos predichos. No deben confundirse por su traducción.
- [ ] Exactitud define una licencia; precisión define un sistema operativo.
  > Son conceptos analíticos, no condiciones de software o plataformas.

<Quiz id="sge-v1-ut2-siglas-integracion-13">
¿Qué asociación es correcta en un panel de clientes?

- [x] NPS mide recomendación; churn expresa bajas.
  > Correcta. NPS es Net Promoter Score, indicador de recomendación. Churn expresa pérdida o tasa de bajas de clientes en un periodo y población definidos.
- [ ] NPS mide piezas defectuosas; churn, memoria del servidor.
  > Son ámbitos distintos de los indicadores de clientes.
- [ ] NPS mide bajas; churn, recomendación.
  > Intercambia el significado de ambos conceptos.
- [ ] NPS define el precio base; churn, el impuesto de venta.
  > Son componentes de precios, no los indicadores de relación con clientes.

En un ERP local, ¿para qué puede utilizarse una VPN?

- [ ] Para calcular la cantidad económica de cada pedido.
  > Esa finalidad corresponde a EOQ.

¿Qué tienen en común AWS, Azure y Google Cloud en el tema?

- [ ] Son tres nombres distintos del módulo de nóminas de Odoo.
  > Son plataformas de nube de proveedores diferentes.

- [x] Son plataformas donde pueden desplegarse sistemas empresariales.

Un gráfico atribuido a IDC muestra cuotas de ingresos de software CRM. ¿Qué indica esa cuota?

- [ ] El porcentaje de aciertos de un modelo de clasificación.
  > Es una métrica de predicción, no participación económica de proveedores.
- [ ] La proporción de empleados que trabaja en remoto.
  > La cuota de ingresos compara proveedores de software, no la organización laboral de los empleados.
- [x] Una participación en ingresos de la categoría estudiada.
  > Correcta. Deben mantenerse año, fuente y definición de mercado. No equivale al porcentaje de todas las empresas que usan el producto ni prueba cuál es el mejor.
- [ ] La probabilidad de que cualquier cliente compre ese producto.
  > Los ingresos del mercado no predicen automáticamente una compra individual.

Un panel muestra +20 % de incidencias y +12 % de ventas. ¿Cómo debe interpretarse?

- [ ] Cualquier aumento debe aparecer siempre en verde.
  > El sentido favorable depende de qué se mide.
- [ ] Toda disminución de un indicador es siempre negativa.
  > Menos defectos, retrasos o costes puede ser positivo.
- [ ] El color del panel demuestra por sí solo una causa.
  > Un estado visual alerta o resume; no prueba qué produjo el cambio.
- [x] Cada indicador necesita contexto y criterio de valoración.
  > Correcta. Más ventas puede ser favorable, mientras que más incidencias exige atención. También conviene relacionarlas con volumen, periodo y metas antes de actuar.
