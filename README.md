## Modelo híbrido

Los módulos técnicos conservan aquí `temario/` y `recursos/`; sus ejercicios y
prácticas pequeñas se desarrollan en el repositorio `-labs` correspondiente. Los
módulos documentales conservan también `tareas/` y `practicas/` en este repositorio.
Las aplicaciones completas tienen repositorio propio y se indexan en `PROYECTOS.md`.

## Criterio de almacenamiento

Este repositorio contiene:

- Apuntes y documentación propios en Markdown.
- Material docente que pueda publicarse legalmente.
- Enunciados, PDF, imágenes y recursos necesarios para trabajar.
- Actividades documentales de los módulos no técnicos.
- Enlaces a laboratorios, prácticas y proyectos independientes.

No contiene secretos, calificaciones, datos personales, dependencias que puedan
descargarse de nuevo ni salidas generadas por los IDE y herramientas de build.
