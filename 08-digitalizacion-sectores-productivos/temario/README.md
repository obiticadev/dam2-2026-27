## Cómo están preparados

- Se desarrollan todos los apartados de las presentaciones, no solo sus conclusiones.
- Se reconstruyen las tablas y esquemas que estaban incrustados como imágenes y no aparecían en la extracción de texto.
- Se mantienen introducciones, ejemplos, recuadros, síntesis, retos y referencias a casos del libro.
- Las aclaraciones editoriales se distinguen del contenido de origen, especialmente cuando el material simplifica o mezcla conceptos.
- Cada tema termina con una tabla de correspondencia y enlaces a las láminas originales de todas sus páginas.
- Los retos se conservan como enunciados: no se han añadido soluciones ni inventado los casos del libro que el PDF solo menciona.
