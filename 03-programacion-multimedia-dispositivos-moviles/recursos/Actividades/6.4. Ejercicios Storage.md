## Ejercicio 1: Gestor de archivos de texto en almacenamiento externo

Crea una aplicación que permita al usuario crear archivos de texto en el
almacenamiento externo, visualizar y/o modificar los archivos existentes y
eliminar aquellos que ya no desee mantener.

La aplicación deberá comprobar tanto que el almacenamiento externo está
disponible, como que existe espacio disponible para almacenar el archivo
generado o modificado.

**Opcional:** Añadir un apartado de preferencias en la aplicación para que el
usuario pueda configurar que espacio de almacenamiento desea utilizar (interno o
externo).

### Requisitos técnicos (Ejercicio 1)

- **Comprobación de estado:**
  - Verificar que el medio esté montado y listo para escritura con
    `Environment.MEDIA_MOUNTED.equals(Environment.getExternalStorageState())`.
- **Cálculo de espacio libre:**
  - Uso de `StatFs` o de los métodos `File.getFreeSpace()` /
    `File.getUsableSpace()` para asegurar capacidad antes de operaciones de E/S.
- **Operaciones de E/S (CRUD):**
  - Creación y edición: `OutputStreamWriter` / `BufferedWriter`.
  - Lectura: `BufferedReader` / `InputStreamReader`.
  - Eliminación: método `delete()` sobre la instancia `File`.
- **Apartado opcional:**
  - Pantalla o diálogo de preferencias (`SharedPreferences`) para alternar entre
    el almacenamiento interno privado (`context.getFilesDir()`) y el externo
    (`context.getExternalFilesDir(null)`).

## Ejercicio 2: Actividad de gestión de ficheros permanentes y temporales

En una aplicación que utilice el internal y/o el external storage, crea una
actividad para gestionar los ficheros almacenados por el usuario, que permita
trabajar tanto con los ficheros permanentes como con los temporales.

### Dicha actividad deberá permitir

- Listar archivos.
- Eliminar archivos.
- Conocer el espacio ocupado y libre.
- Ser invocada desde las aplicaciones de administración del dispositivo.

### Puntos clave de implementación (Ejercicio 2)

- **Separación de ámbitos:**
  - Ficheros permanentes: directorios devueltos por `getFilesDir()` y
    `getExternalFilesDir()`.
  - Ficheros temporales / caché: directorios devueltos por `getCacheDir()` y
    `getExternalCacheDir()`.
- **Métricas de ocupación:**
  - Recorrido iterativo de los arrays de archivos para calcular el tamaño
    acumulado en bytes (`File.length()`).
  - Consulta de espacio disponible mediante `File.getTotalSpace()` y
    `File.getFreeSpace()`.
- **Invocación externa:**
  - Declaración en el `AndroidManifest.xml` de un `<intent-filter>` adecuado en
    la actividad para responder a acciones estándar del gestor de archivos o de
    la configuración del sistema.
