## Un recorrido para aprender, no solo sacar nota

1. Consulta la guía o intenta primero un cuestionario para detectar dudas.
2. Responde y pulsa **Enviar**. Lee el porqué, también al acertar.
3. Marca las preguntas que necesites repasar y vuelve a ellas desde el navegador lateral.
4. Practica los tres bloques de cada examen antes de pasar al global.
5. Reinicia el intento para barajar preguntas y opciones. Los enunciados no cambian al reiniciar: se reorganiza el banco de esa página.

El progreso, las marcas y el cronómetro se guardan en **este navegador y este dispositivo**. No hay cuenta ni sincronización. En Reading, cada pregunta lleva su lectura completa para no perder el contexto al barajar. No hay tiempo límite ni penalización oficial definida.
